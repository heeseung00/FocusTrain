## 1. 프로젝트 개요

---

### 한 줄 정의

기차표 기반 집중 타이머 웹앱 ‘Focus Trip’

### 제품 목표

기차 여행의 출발·이동·도착 경험을 집중 학습 과정에 적용하여, 사용자가 공부를 시작하기 어려운 순간에도 흥미롭게 세션을 시작하고 목표 시간까지 자연스럽게 집중할 수 있도록 지원한다. 사용자는 기차 종류, 출발역, 목적역, 이동 시간, 중간 휴식 여부를 설정하고 실제 여정을 선택하는 것처럼 집중 세션을 구성할 수 있다.

### 배경

Focus Trip은 대학생과 자격증 준비생이 혼자 공부할 때 겪는 시작의 어려움, 주의 산만, 집중 동기 저하를 해결하기 위한 집중 타이머다. 일반적인 생산성 앱의 추상적인 타이머 대신 KTX 승차권과 철도 안내 시스템의 시각 언어를 활용한다. 전체 화면은 거의 흰색에 가까운 밝은 회색 배경, 흰색 티켓형 카드, 검정 및 짙은 회색 텍스트, 선명한 레드 포인트로 구성한다. 얇은 구분선, 절취선, 원형 절취 디테일, 작은 역명·열차번호·좌석번호 라벨, 모노스페이스 숫자 표현을 활용하되 실제 승차권을 그대로 복제하지 않고 집중 여정을 표현하는 독자적인 인터페이스로 설계한다.

### 사용자 문제

혼자 공부하는 사용자는 공부를 해야 한다는 사실을 알고 있어도 시작 자체를 미루기 쉽다. 일반적인 타이머는 단순히 시간을 세는 기능에 그쳐 시작 동기와 과정의 몰입감을 충분히 제공하지 못하며, 집중 중에는 알림과 주변 자극으로 쉽게 흐름이 끊길 수 있다. 또한 긴 학습 시간을 한 번에 설정하면 부담을 느끼거나 목표를 현실적으로 계획하기 어렵다.

### 해결 방안

사용자가 기차표를 예매하듯 첫화면에서는 기차 종류와 출발지·목적지를 선택하고, 목적지까지의 이동 시간을 집중 세션으로 설정하도록 한다. 세션 시작 화면에서는 출발역, 목적역, 열차 정보, 좌석 정보, 출발 시각, 도착 예정 시각을 티켓 형태로 보여준다. 집중 중에는 현재 역과 목적지, 남은 이동 시간, 진행 상태를 명확히 표시하며, 필요에 따라 중간 정차역을 휴식 구간으로 설정할 수 있다. 사용자가 원하는 추가 집중 시간을 직접 입력할 수도 있어 짧은 공부부터 긴 학습까지 유연하게 대응한다.

### 차별점

일반적인 뽀모도로 타이머와 달리 고정된 25분 단위가 아니라 ‘출발지에서 목적지까지 이동한다’는 서사형 세션을 제공한다. 기차표의 정보 구조와 절취선 디자인을 전체 UI에 일관되게 적용하여 단순 타이머보다 높은 시작 동기와 몰입감을 만든다. KTX, ITX, 무궁화 등 열차 종류와 역 선택을 통해 사용자가 자신의 공부 시간을 구체적인 여정으로 인식하게 하며, 중간 정차 휴식과 사용자 지정 시간을 함께 제공하는 것이 차별점이다.

### 타겟 사용자

주요 사용자는 대학생과 자격증 준비생이다. 시험 기간이나 과제·학습 목표를 앞두고 혼자 공부하는 시간이 많으며, 공부 계획은 세우지만 시작을 미루거나 집중 흐름을 자주 잃는다. 생산성 도구를 사용해 본 경험은 있으나 복잡한 설정과 지나치게 화려한 화면을 선호하지 않는다. 모바일에서는 짧은 학습 세션을 빠르게 시작하고, 웹이나 데스크톱에서는 긴 시간 동안 타이머를 띄워 두고 공부하는 상황이 많다. 기차 여행, 예매, 목적지 도착과 같은 명확한 진행 구조에 친숙하고, 차분하면서도 개성 있는 학습 도구를 선호한다.

### 사용자 시나리오

1. 사용자가 첫 화면에서 KTX, ITX, 무궁화 중 하나를 선택하고 출발역과 목적역을 지정한다. 2. 시스템이 선택한 여정에 맞는 기본 이동 시간을 제안하고, 사용자는 해당 시간을 그대로 사용하거나 추가 시간을 직접 입력한다. 3. 사용자가 중간 정차역 휴식을 활성화하면 집중 구간과 휴식 구간이 여정에 포함된다. 4. 사용자는 기차표 형태의 세션 요약을 확인한 뒤 ‘여정 시작’ 버튼을 눌러 집중을 시작한다. 5. 집중 화면에서는 현재 위치, 목적지, 열차 정보, 남은 시간, 도착 예정 시각을 확인하며 다른 화면 요소는 최소화된다. 6. 중간 정차 시 휴식 안내가 표시되고, 휴식이 끝나면 다음 구간 집중을 시작할 수 있다. 7. 목적지에 도착하면 세션 완료 화면에서 총 집중 시간, 정차 횟수, 완료 상태를 확인하고 새로운 여정을 다시 설정할 수 있다.

### 핵심 지표

핵심 지표는 첫 세션 시작률, 세션 시작까지 걸린 평균 시간, 세션 완료율, 평균 집중 시간, 중간 이탈률, 재방문율, 주간 활성 사용자 수다. 초기 목표는 첫 방문 사용자의 세션 시작률 60% 이상, 시작한 세션의 완료율 65% 이상, 세션 시작까지 평균 소요 시간 60초 이하, 7일 내 재방문율 25% 이상으로 설정한다. 추가로 기차 종류·여정·휴식 설정 사용률과 사용자 지정 시간 사용률을 측정해 핵심 기능의 활용도를 확인한다.

### 리스크

기차역과 이동 시간 데이터가 부정확하면 사용자가 여정의 신뢰성을 잃을 수 있다. 설정 단계가 지나치게 많으면 시작을 쉽게 만든다는 목표와 충돌할 수 있으므로 기본값과 빠른 시작이 필요하다. 기차 콘셉트가 학습보다 장식적으로 느껴지거나 실제 기차표를 과도하게 모방하면 차별성과 사용성이 저하될 수 있다. 타이머가 백그라운드에서 멈추거나 브라우저 알림이 차단되면 세션 기록이 부정확해질 수 있다. 모바일과 데스크톱에서 화면 크기와 입력 방식이 달라 핵심 정보가 잘리거나 설정 과정이 복잡해질 위험도 있다.

## 1. 기차 여정 설정

> **중요도**: 🔴 높음 | **진행 상태**: ⚪ 기획 작성중

사용자가 첫 화면에서 기차 종류를 선택하고 서울을 출발역으로 하여 서비스에서 제공하는 일부 대표 목적역을 설정할 수 있어야 한다. 기차 종류는 KTX, ITX, 무궁화를 기본 제공하며, data.json에 저장된 기차 종류별·목적역별 대략적인 이동 시간을 기본 집중 시간으로 제안한다. 초기 버전에서는 데이터에 등록된 여정만 선택할 수 있으며, 실제 철도 운행 정보의 실시간 조회는 포함하지 않는다.

**수용 기준:**

```
1. ○ 첫 화면에서 KTX, ITX, 무궁화 선택지가 명확하게 표시된다.
2. ○ 출발역은 서울로 고정하고, 목적역은 data.json에 등록된 일부 대표 역 목록에서 선택할 수 있다.
3. ○ 기차 종류와 목적역을 설정하면 data.json의 해당 조합에 저장된 기본 이동 시간과 도착 예정 시각이 표시된다.
4. ○ data.json에 등록되지 않은 기차 종류·목적역 조합은 선택할 수 없거나 지원하지 않는 여정이라는 안내가 표시된다.
5. ○ 필수 항목이 입력되지 않은 경우 여정 시작 버튼이 비활성화되거나 안내 메시지가 표시된다.
6. ○ 모바일과 데스크톱에서 선택 영역과 주요 입력 항목이 모두 정상적으로 표시된다.
```

### 1.1 기본 이동 시간 제안

> **중요도**: 🔴 높음 | **진행 상태**: ⚪ 기획 작성중 | **역할**: 사용자 | **기기**: 웹, 모바일, 데스크톱

사용자는 기차 종류와 서울 출발 목적역을 선택해 해당 여정의 기본 집중 시간을 확인할 수 있다. 서비스는 data.json에 등록된 일부 대표 역 조합의 대략적인 소요 시간을 사용하며, 지원하지 않는 조합의 시간은 제안하지 않는다. 실제 철도 운행 시간의 실시간 조회는 이 기능 범위에 포함하지 않는다.

**개발 준비 슬롯**

- **선행조건**: - 서울 출발 목적역과 기차 종류의 조합이 data.json에 등록되어 있어야 한다.
- **트리거**: - 사용자가 기차 종류와 목적역을 선택하면 기본 이동 시간 조회를 시작한다.
- **동작**: - 시스템은 선택한 기차 종류와 목적역 조합으로 data.json을 조회한다.
    - 시스템은 일치하는 대략적 소요 시간을 기본 집중 시간으로 적용한다.
    - 시스템은 기본 집중 시간을 기준으로 도착 예정 시각을 계산한다.
- **결과**: - 선택한 여정의 기본 집중 시간과 도착 예정 시각을 사용자에게 표시한다.
- **예외**: - data.json에 없는 기차 종류와 목적역 조합은 기본 이동 시간을 제안하지 않는다.
- **표시**: - 기본 이동 시간과 도착 예정 시각은 여정 설정 화면에서 기차 종류와 목적역 선택 후 표시한다.
- **권한 & 접근**: - 비로그인 사용자를 포함한 모든 사용자가 기본 이동 시간 제안을 사용할 수 있다.
- **비즈니스 규칙**: - 기본 이동 시간은 실시간 철도 운행 정보가 아닌 data.json의 기차 종류별·목적역별 대략적인 소요 시간을 기준으로 한다.
    - 출발역은 서울로 고정한다.
- **데이터**: - data.json은 기차 종류, 출발역, 목적역, 기본 이동 시간을 각 여정 조합별로 저장한다.

## 2. 집중 시간 및 휴식 설정

> **중요도**: 🔴 높음 | **진행 상태**: ⚪ 기획 작성중

사용자가 목적지까지의 기본 이동 시간을 그대로 사용하거나 원하는 추가 시간을 직접 입력할 수 있어야 한다. 중간 정차역 휴식 기능을 켜고 끌 수 있으며, 활성화한 경우 집중 구간과 휴식 구간이 세션에 반영되어야 한다.

**수용 기준:**

```
1. ○ 사용자는 기본 이동 시간을 선택하거나 사용자 지정 집중 시간을 입력할 수 있다.
2. ○ 사용자 지정 시간은 허용된 최소·최대 범위 안에서만 저장된다.
3. ○ 중간 정차 휴식 설정을 활성화하면 휴식 시간과 정차 횟수를 설정할 수 있다.
4. ○ 설정된 집중 시간, 휴식 시간, 전체 예상 소요 시간이 세션 요약에 표시된다.
5. ○ 시간 형식은 모든 화면에서 일관되게 표시되고 잘못된 입력에는 수정 방법이 안내된다.
```

## 3. 티켓형 세션 시작 화면

> **중요도**: 🔴 높음 | **진행 상태**: ⚪ 기획 작성중

설정한 여정을 실제 기차표처럼 확인할 수 있는 세션 요약 카드를 제공한다. 카드에는 열차 종류, 열차 번호, 출발역, 목적역, 출발 시각, 도착 예정 시각, 좌석 또는 세션 번호, 집중 시간이 포함되어야 한다. 넓은 화이트 카드, 얇은 구분선, 절취선, 작은 라벨, 검정 중심의 타이포그래피와 선명한 레드 포인트를 사용한다.

**수용 기준:**

```
1. ○ 세션 시작 전 티켓형 요약 카드에 사용자가 설정한 여정 정보가 정확히 표시된다.
2. ○ 출발역과 목적역이 가장 큰 정보 위계로 표시되고 보조 정보는 작은 라벨로 구분된다.
3. ○ 절취선과 원형 절취 디테일이 장식적으로 사용되며 주요 정보를 가리지 않는다.
4. ○ 여정 시작 버튼은 화면에서 명확하게 식별되며 한 번의 주요 동작으로 세션을 시작할 수 있다.
5. ○ 배경은 밝은 회색, 콘텐츠 카드는 흰색, 주요 포인트 컬러는 레드 중심으로 유지된다.
```

## 4. 집중 진행 화면

> **중요도**: 🔴 높음 | **진행 상태**: ⚪ 기획 작성중

세션이 시작되면 사용자가 현재 집중 상태와 남은 시간을 즉시 파악할 수 있는 집중 화면을 제공한다. 현재 구간, 출발역, 목적역, 남은 시간, 진행률, 도착 예정 시각을 표시하고 시각적 장식을 최소화해 학습 방해를 줄인다.

**수용 기준:**

```
1. ○ 세션 시작 후 남은 시간이 초 단위 또는 분·초 단위로 실시간 갱신된다.
2. ○ 현재 집중 구간과 다음 휴식 또는 도착 상태가 명확하게 표시된다.
3. ○ 진행률은 선형 표시 또는 철도 노선 형태로 표현되며 현재 위치를 확인할 수 있다.
4. ○ 브라우저 탭 전환이나 화면 잠금 이후에도 타이머 시간이 실제 경과 시간과 일치한다.
5. ○ 일시 정지, 재개, 세션 종료 기능을 제공하고 종료 시 사용자에게 확인을 요청한다.
```

## 5. 중간 정차 휴식 및 세션 완료

> **중요도**: 🟡 중간 | **진행 상태**: ⚪ 기획 작성중

중간 정차를 설정한 경우 집중 구간이 끝날 때 휴식 안내 화면을 제공하고, 휴식 종료 후 다음 구간을 이어서 진행할 수 있게 한다. 최종 목적지에 도착하면 세션 완료 결과와 다음 행동을 제공한다.

**수용 기준:**

```
1. ○ 정차 구간 시작 시 현재 집중 구간이 종료되고 휴식 상태가 명확히 표시된다.
2. ○ 휴식 타이머가 설정된 시간만큼 동작하며 휴식 종료 시 다음 집중 시작 안내가 표시된다.
3. ○ 사용자는 휴식을 건너뛰거나 다음 집중 구간으로 이동할 수 있다.
4. ○ 최종 완료 화면에 총 집중 시간, 완료한 구간 수, 설정한 목적지가 표시된다.
5. ○ 완료 후 새로운 여정을 시작하거나 동일한 설정으로 다시 시작할 수 있다.
```

## 6. 반응형 및 접근성 UI

> **중요도**: 🔴 높음 | **진행 상태**: ⚪ 기획 작성중

모바일, 웹, 데스크톱 환경에서 동일한 핵심 경험을 제공하도록 반응형 레이아웃을 구성한다. 작은 화면에서는 설정 항목을 단계적으로 배치하고, 큰 화면에서는 티켓형 카드와 타이머를 충분한 여백으로 배치한다. 색상 대비, 키보드 조작, 명확한 라벨을 보장한다.

**수용 기준:**

```
1. ○ 모바일 세로 화면, 태블릿 또는 일반 웹 화면, 데스크톱 화면에서 콘텐츠가 가로로 잘리지 않는다.
2. ○ 모바일에서는 기차 설정, 시간 설정, 세션 요약이 자연스러운 순서로 표시된다.
3. ○ 주요 버튼과 입력 요소는 터치 조작에 충분한 크기를 가진다.
4. ○ 텍스트와 배경의 명도 대비가 읽기 가능한 수준으로 유지된다.
5. ○ 키보드만으로 주요 입력과 여정 시작·일시 정지·종료 기능을 사용할 수 있다.
6. ○ 모든 아이콘과 입력 요소에 사용 목적을 알 수 있는 텍스트 라벨 또는 접근성 이름이 제공된다.
```
